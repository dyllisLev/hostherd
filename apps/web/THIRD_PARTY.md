# UI attribution

The local UI component patterns and dashboard composition adapt shadcn/ui's
dashboard-01 (sidebar, inset content, metric cards, activity chart and data table)
for React/Vite and Hostherd's live server data.

Source: https://ui.shadcn.com/r/styles/new-york-v4/dashboard-01.json
Project: https://github.com/shadcn-ui/ui
